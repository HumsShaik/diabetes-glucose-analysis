# Dataset Description

This folder contains the HUPA-UCM Diabetes Dataset used in this project.

## Dataset Source
HUPA-UCM Diabetes Dataset

## Data Contents
- Continuous glucose monitoring readings
- Insulin administration data
- Carbohydrate intake
- Heart rate
- Calories burned
- Step counts
- Patient identifiers

## Folder Structure
- raw/ → Original dataset files
- processed/ → Cleaned and transformed datasets
